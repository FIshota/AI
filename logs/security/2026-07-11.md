## 🚨 Critical / High Findings (pip-audit)

### CVE-2026-44405 — `paramiko 3.5.1` [HIGH]
- **Alias:** GHSA-r374-rxx8-8654
- **Fix Version:** No fixed version released yet
- **Description:** In Paramiko through 4.0.0 (before commit a448945), `rsakey.py` allows the SHA-1 algorithm. SHA-1 is cryptographically broken and its use in RSA key operations weakens authentication security.
- **Impact:** Weakened SSH authentication; potential downgrade attack.
- **Action:** Monitor for a patched release; consider pinning to a fork or mitigating by enforcing SHA-256/SHA-512 at the server configuration level.

---

### CVE-2025-69872 — `diskcache 5.6.3` [HIGH]
- **Alias:** GHSA-w8v5-vhqr-4h9v
- **Fix Version:** No fixed version released yet
- **Description:** DiskCache (python-diskcache) through 5.6.3 uses Python `pickle` for serialization by default. An attacker with write access to the cache directory can plant a malicious pickle payload, leading to arbitrary code execution on deserialization.
- **Impact:** Remote/local code execution if cache storage is attacker-controllable.
- **Action:** Restrict write permissions to the diskcache directory. Evaluate migrating to a safer serializer (JSON) or replacing diskcache with a non-pickle alternative.

---

### PYSEC-2026-1325 / CVE-2024-23342 — `ecdsa 0.19.2` [HIGH]
- **Alias:** GHSA-wj6h-64fc-37mp
- **Fix Version:** No fixed version released yet
- **Description:** python-ecdsa is subject to a Minerva timing side-channel attack on the P-256 curve. An attacker who can measure many signing operations may recover the private key.
- **Impact:** Private key extraction via timing analysis; cryptographic identity compromise.
- **Action:** Replace `ecdsa` with `cryptography` (PyCA) for all signing operations, which uses constant-time implementations.

## Recommendations (Priority Order)

1. **[URGENT] Upgrade `cryptography` from 41.0.7 → 49.x** — This library is used throughout the codebase and spans 8 major versions with numerous CVE fixes. Run `pip install --upgrade cryptography` and verify no API breakage.

2. **[HIGH] Replace `ecdsa` with PyCA `cryptography`** — `ecdsa` has an unfixed timing attack vulnerability (CVE-2024-23342). The `cryptography` package provides constant-time ECDSA implementations and is already a dependency.

3. **[HIGH] Audit `diskcache` write-access permissions** — Until CVE-2025-69872 is patched, ensure the cache directory (`~/.cache/ai-chan/` or equivalent) is not writable by untrusted processes. Consider switching the serializer or replacing diskcache entirely.

4. **[MEDIUM] Review B608 SQL query construction in `core/conversation_search.py:306,368`** — Column and table names are interpolated via f-strings. Confirm all values come from a controlled allowlist; add `# nosec B608` with justification comment if intentional.

5. **[MEDIUM] Monitor `paramiko` for a CVE-2026-44405 patch** — No fix version is available yet. Track GHSA-r374-rxx8-8654 and update as soon as a release is published. Consider enforcing RSA-SHA2-256/512 on the SSH server side to mitigate.
