## 🚨 Critical / High Findings

### HIGH — CVE-2025-69872 · diskcache 5.6.3

| Field | Detail |
|---|---|
| **Package** | `diskcache` 5.6.3 |
| **CVE** | CVE-2025-69872 / GHSA-w8v5-vhqr-4h9v |
| **Fix Version** | None available yet (upstream unfixed) |
| **Impact** | DiskCache uses Python `pickle` for serialization by default. An attacker with **write access to the cache directory** can achieve **arbitrary code execution** when a victim application deserializes a malicious cache entry. |
| **Action** | Audit who/what can write to the cache directory; consider switching serialization to JSON or msgpack via `DiskCache(disk=JSONDisk)`. Pin + monitor upstream for patch. |

| **Fix Version** | None available (upstream: commit a448945 not yet in a release) |

### PYSEC-2026-1325 · ecdsa 0.19.2

| Field | Detail |
|---|---|
| **CVE** | CVE-2024-23342 / GHSA-wj6h-64fc-37mp |
| **Fix Version** | None available |
| **Impact** | python-ecdsa is subject to a Minerva timing attack on P-256. Timing analysis of `sign_digest()` can leak the private key. |

## Recommendations (Priority Order)

1. **[IMMEDIATE] Audit diskcache write-access surface** — CVE-2025-69872 allows RCE if cache directory is attacker-writable. Switch to `JSONDisk` or restrict permissions until a patched release is available.

2. **[HIGH] Upgrade `cryptography` from 41.0.7 → 49.0.0** — This core security library is 8 major versions behind. Security fixes accumulate; upgrade should be tested in a branch and deployed promptly.

3. **[MEDIUM] Review `urllib.request.urlopen` call sites** — In `github_learner.py`, `image_gen.py`, and `research_agent.py`: validate that URLs come from trusted sources only and are restricted to `https://` schemes before calling `urlopen`. Existing `# noqa: S310` comments suggest awareness but validation should be confirmed.

4. **[MEDIUM] Harden `server_home.py` Paramiko calls** — Static strings like `"echo ok"` and `"uptime -p"` are safe, but the dynamic `exec_command(cmd)` at line 265 must have `cmd` validated/whitelisted to prevent shell injection if `cmd` originates from user input.

5. **[LOW] Monitor `paramiko` and `ecdsa` upstream** — Both have unfixed CVEs. Subscribe to GHSA-r374-rxx8-8654 and GHSA-wj6h-64fc-37mp for patch notifications; upgrade immediately when fixes land.
