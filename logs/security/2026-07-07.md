## Recommendations (優先度順)

1. **[CRITICAL] `diskcache` pickle RCE (CVE-2025-69872)**
   修正バージョン未リリース。`diskcache` をキャッシュバックエンドとして使用している箇所を特定し、`msgpack` / `json` シリアライザに切り替えるか、キャッシュディレクトリのファイルシステム権限を最小化 (アプリ専用ユーザのみ書き込み可) する。Issue #1 参照。

2. **[HIGH] `paramiko` SHA-1 許可 (CVE-2026-44405)**
   コミット `a448945` 以降の upstream 修正を追跡し、リリース次第アップデート。暫定策として SSH 接続時に `preferred_algorithms` で SHA-1 を排除する設定を追加する。`core/server_home.py` の Paramiko 利用箇所を確認。

3. **[MEDIUM] SQL インジェクション (`core/conversation_search.py:306,368`)**
   f-string でテーブル名・カラム名を組み立てている。テーブル名はホワイトリスト検証、動的 WHERE 句はパラメータバインディングに置き換える (B608 完全解消)。

4. **[MEDIUM] Paramiko shell injection (`core/server_home.py` 6 箇所)**
   `exec_command` に渡すコマンド文字列が外部入力を含む可能性。コマンドをハードコードするか、shlex.quote() でエスケープ。長期的には Paramiko の SFTP/チャンネル API を使いシェル呼び出しを排除。

5. **[MEDIUM] Major version drift (cryptography 41→49, setuptools 68→83)**
   `cryptography` はセキュリティパッチを多数含む。テスト環境でアップグレードし、互換性確認後 requirements.txt に反映する。
