## 🚨 Critical / High Findings

### CVE-2026-44405 — paramiko 3.5.1 · **HIGH**

- **GHSA**: GHSA-r374-rxx8-8654
- **Fix Version**: No fix released yet (upstream patch commit `a448945` in progress)
- **Description**: Paramiko through 4.0.0 allows the SHA-1 algorithm in RSA key operations (`rsakey.py`). SHA-1 is cryptographically broken; this enables collision-based attacks against RSA host key verification.
- **Impact**: SSH host key spoofing / MitM risk in `core/server_home.py`

### CVE-2025-69872 — diskcache 5.6.3 · **HIGH**

- **GHSA**: GHSA-w8v5-vhqr-4h9v
- **Fix Version**: No fix released yet
- **Description**: DiskCache uses Python `pickle` for serialization by default. An attacker with write access to the cache directory can achieve **arbitrary code execution** when a victim application reads back a poisoned cache entry.
- **Impact**: RCE if cache directory (`/tmp/diskcache` or configured path) is writable by untrusted processes

## ⚠ Medium Findings (CVE)

### PYSEC-2026-1325 / CVE-2024-23342 — ecdsa 0.19.2 · **MEDIUM**

- **GHSA**: GHSA-wj6h-64fc-37mp
- **Fix Version**: No fix released yet
- **Description**: `python-ecdsa` is subject to a **Minerva timing attack** on the P-256 curve. Timing of `sign_digest()` can leak the internal nonce `k`, allowing private key recovery.
- **Impact**: Private key extraction if ECDSA P-256 signing is exposed to timing side-channels

## Recommendations (Priority Order)

1. **[HIGH] Patch paramiko (CVE-2026-44405)** — Pin to the post-`a448945` commit or switch to `asyncssh`/`fabric` while awaiting a released fix. SHA-1 in RSA host key verification exposes `core/server_home.py` SSH connections to MitM.

2. **[HIGH] Harden diskcache usage (CVE-2025-69872)** — Switch from default pickle serializer to JSON/msgpack (`DiskCache(serializer=JSONDisk)`) or restrict cache directory permissions (`chmod 700`). Consider replacing diskcache with Redis/valkey which does not use pickle by default.

3. **[MEDIUM] Update `cryptography` 41→49 (8 major versions)** — Run `pip install --upgrade cryptography` and validate. This library underpins TLS/JWT operations throughout the codebase.

4. **[MEDIUM] Fix paramiko `exec_command` calls (B601 × 6 in `core/server_home.py`)** — All commands are string literals which are safe today, but the pattern invites future injection. Wrap with an allowlist validator before the `exec_command` call.

5. **[MEDIUM] Address ecdsa Minerva timing (PYSEC-2026-1325)** — Replace `ecdsa` with `cryptography.hazmat.primitives.asymmetric.ec` (constant-time P-256 implementation). Alternatively, restrict `ecdsa` usage to non-sensitive operations not exposed to timing side-channels.
